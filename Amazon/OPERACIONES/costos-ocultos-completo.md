# Costos Ocultos Amazon FBA 2026 — Guía Completa

## Por qué los sellers pierden dinero sin saberlo

El error más común: calcular solo referral fee + FBA fee + COGS. Eso es el 60% del costo real.
El 40% restante son los "costos invisibles" que destruyen el margen de la mayoría.

---

## MAPA COMPLETO DE COSTOS (por unidad vendida)

### Grupo A — Costos que todos calculan ✅

| Costo | Rango | Notas |
|---|---|---|
| Referral fee | 8–15% del PVP | Según categoría. Home & Kitchen: 15%. Pet: 15%. Health: 8%. |
| FBA fulfillment fee | $3.50–$9.61 | Por peso y tamaño. Ver tabla en Seller Central. |
| COGS (producto) | Variable | Costo FOB en fábrica, sin shipping |

### Grupo B — Costos que se calculan mal (o no se calculan) ⚠️

| Costo | Monto real | Cómo calcularlo |
|---|---|---|
| **Shipping China → USA (aéreo)** | $5–12/kg real | $7/kg promedio 2026. Para 1kg de producto → $7/unidad |
| **Shipping China → USA (marítimo)** | $2.10/kg DDP | Mejor opción para inventarios > 300 unidades |
| **Import duties & tariffs** | 12–25% del FOB | Tarifa base HTS + Section 301 tariffs (específicos China) |
| **Customs broker fee** | $125–300/envío | Se divide entre las unidades del envío |
| **Amazon Inbound Placement Fee** | $0.27–$1.58/unidad | Varía según si mandás a 1 o múltiples warehouses |
| **FBA prep center** | $0.50–$1.20/unidad | Si no hacés vos el prep (polybag, labels, etc.) |
| **Professional Seller Account** | $39.99/mes | ÷ unidades vendidas ese mes |

### Grupo C — Costos que casi nadie calcula ❌

| Costo | Monto real | Impacto en margen |
|---|---|---|
| **Monthly storage (Ene–Sep)** | $0.78/ft³/mes | Producto 1ft³ durante 3 meses = $2.34 extra |
| **Monthly storage (Oct–Dic)** | $2.40/ft³/mes | 3x más caro en Q4. Planificar reabastecimiento |
| **Aged inventory surcharge (181+ días)** | $0.50–$6.90/ft³ adicional | Si el stock no rota, empieza a generar fees exponenciales |
| **Tasa de devoluciones (returns)** | 5–25% según categoría | Clothing: 25%. Home: 8–12%. Pet: 5–8%. |
| **Returns processing fee** | $2–$5/devolución | Solo si la categoría tiene alta tasa de returns |
| **Refund admin fee (Amazon se queda)** | $5 o 20% del referral | Amazon no devuelve todo cuando el cliente devuelve |
| **Inventario dañado/perdido en warehouse** | 1–3% del inventario | Amazon cubre solo una parte. El resto, pérdida tuya |
| **Disposal fee** | $0.97–$3.00/unidad | Para stock que no vende y hay que retirar |
| **Removal order fee** | $0.97–$2.00/unidad | Para retirar stock de FBA a tu dirección |
| **Unplanned service fee** | $0.30–$1.30/unidad | Si el producto llega mal preparado a Amazon |
| **Photography (amortizada)** | $0.30–$1.00/unidad | $300 de fotos ÷ 500 unidades del primer lote |
| **Muestras y desarrollo** | $0.20–$0.50/unidad | $150 de muestras ÷ primer pedido |
| **Brand Registry** | $300/año ÷ unidades | Si vendés 1.000 unidades/año = $0.30/unidad |
| **Product liability insurance** | $500–$1.200/año | Obligatorio para marcas serias. ~$0.50–$1.20/unidad |
| **Accounting/bookkeeping** | $50–200/mes | Sellerboard u contador. ~$0.30–$1.00/unidad |
| **Amazon reserve de pagos** | 7+ días de flujo retenido | No es un costo, pero SÍ es capital inmovilizado |

## Regla del "Factor 2.5x"

Para calcular rápido si un producto tiene margen viable:
- El precio de venta objetivo debe ser **al menos 2.5x el COGS FOB**
- Si COGS = $8 → PVP mínimo viable = $20
- Si COGS = $15 → PVP mínimo viable = $37.50

Esto da espacio para absorber todos los costos ocultos y aún tener margen.

Con factor 3x o más → producto excelente.
Con factor 2–2.5x → producto marginal, muy sensible a cambios de fees o PPC.
Con factor < 2x → NO lanzar.

## Checklist financiero antes de hacer el pedido

- [ ] P&L calculado con TODOS los costos del Grupo A, B y C
- [ ] Factor 2.5x verificado
- [ ] Margen neto > 20% después de PPC al 20%
- [ ] Capital de trabajo calculado: inventario + shipping + PPC mes 1 = total a financiar
- [ ] Break-even en unidades calculado
- [ ] Tariff rate confirmado con el HTS code exacto del producto
- [ ] Tasa de devolución estimada (consultar categoría en Seller Central)
- [ ] Flujo de caja proyectado a 6 meses (Amazon paga cada 14 días con 7 días de reserve)
