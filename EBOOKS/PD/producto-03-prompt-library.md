## Concepto del producto

### Por qué los prompt packs funcionan

Los prompt packs son el producto digital más comprado en Etsy y Gumroad en la categoría IA. Razones:
- **Precio de impulso:** $37-47 no requiere mucha deliberación
- **Resultado instantáneo:** El comprador puede usar el producto en minutos de comprarlo
- **Percepción de valor:** "200 prompts" suena a mucho contenido por poco dinero
- **Reutilización infinita:** A diferencia de un ebook que se "lee y termina", los prompts se usan todos los días

### El problema que resuelve

Dos perfiles de comprador con el mismo problema:
1. **El principiante:** "No sé cómo pedirle las cosas a Claude para que me dé respuestas útiles"
2. **El avanzado:** "Sé usar Claude pero me lleva 15 minutos escribir el prompt perfecto para cada tarea — necesito templates"

### Lo que hace diferente a este prompt pack

**No son prompts genéricos.** Cada prompt:
- Tiene contexto específico de negocio (no "escribe un email", sino "escribe un email de seguimiento de propuesta no respondida, para cliente B2B del sector inmobiliario")
- Incluye variables entre `{{corchetes}}` para customizar en segundos
- Trae un ejemplo real de output esperado
- Tiene nota de "cuándo usar este prompt" (1 línea)

```python
Eres un experto en prompt engineering para negocios con Claude.
Tu trabajo es crear prompts de alta calidad que:

4. Incluyan contexto implícito que mejore el resultado

FORMATO de cada prompt:
---
ID: [número]
Nombre: [nombre descriptivo de 5-7 palabras]
Categoría: [categoría]
Cuándo usarlo: [1 línea - situación específica]
Nivel: [Básico/Intermedio/Avanzado]

PROMPT:
[El prompt completo, listo para copiar]

EJEMPLO DE OUTPUT ESPERADO:
[3-5 líneas mostrando qué tipo de respuesta genera]
---
"""

USER: "Genera los 30 prompts de la Categoría 1: Marketing y Contenido.
ICP del usuario: emprendedor o profesional independiente con negocio de servicios."
```

```python
# FASE 2: Validación de calidad
```
