## Estructura del ebook (80-100 páginas)

### Módulo 0 — Por qué Claude cambia el juego en Amazon FBA (8 páginas)

### Módulo 1 — Product Research con Claude (25 páginas)
- **Cap 1:** El Framework de los 3 Filtros con prompts de Claude
  - Filtro 1 (descarte rápido): Pegar datos de Helium 10 → Claude analiza en 30 segundos
  - Filtro 2 (análisis profundo): Prompt de evaluación de nicho (demanda, competencia, trend)
  - Filtro 3 (P&L completo): Template de Excel + Claude valida los números
- **Cap 2:** Análisis de competencia de listings con Claude
  - Cómo extraer las debilidades de los top 10 competidores
  - El prompt de "análisis de reviews negativas" → brief de producto
  - Cómo identificar el ángulo de diferenciación con IA
- **Cap 3:** Encontrar keywords con gap usando Claude
  - Pegar data de Helium 10 Magnet → Claude identifica oportunidades
  - El prompt de "sub-nicho finder" (el mismo usado en este análisis)
  - Construir la keyword matrix con Claude

### Módulo 2 — Sourcing y Comunicación con Alibaba con IA (15 páginas)
- **Cap 4:** Generar preguntas de proveedor con Claude
  - El prompt maestro de 10 preguntas por tipo de producto
  - Cómo interpretar las respuestas y detectar red flags con IA
- **Cap 5:** Calcular el P&L completo con Claude
  - El template de costos ocultos explicado
  - Cómo usar Claude para verificar los cálculos y encontrar costos que olvidaste
  - Simulación de escenarios (precio más alto, envío marítimo, escala)

### Módulo 3 — Listing Optimization con Claude (20 páginas)
- **Cap 6:** Título optimizado en 5 minutos
  - La fórmula del título de Amazon: [Marca] + [Keyword principal] + [Features] + [Tamaño/Variante]
  - El prompt que genera 5 variantes de título y las rankea por potencial
- **Cap 7:** Bullet points que venden
  - La estructura HAPS (Hook + Attribute + Problem solved + Social proof)
  - Prompts para cada bullet: funcionalidad, diferenciación, objeción, uso, garantía
  - Cómo incluir keywords de forma natural (density sin keyword stuffing)
- **Cap 8:** Descripción + A+ Content con IA
  - El prompt de descripción para compradores emocionales vs. racionales
  - Estructura de A+ Content: 6 módulos óptimos y su copy
  - Backend keywords: el prompt que genera los 249 bytes exactos
- **Cap 9:** Respuestas a reviews negativas con Claude
  - El prompt de respuesta empática-profesional en 60 segundos
  - Cómo convertir una review 2★ en promotor de marca

### Módulo 4 — PPC y Análisis de Datos con Claude (15 páginas)
- **Cap 10:** Estructura de campaña PPC validada por IA
  - El framework de 4 campañas (Auto + Manual Exact + Competitor ASIN + Brand)
  - Cómo usar Claude para interpretar el Search Term Report
  - Prompt para identificar keywords a negativizar
- **Cap 11:** Leer los datos de Seller Central con Claude
  - Pegar el Business Report → Claude identifica oportunidades y problemas
  - El "weekly analysis prompt": 10 minutos de análisis → plan de acción
  - Cómo detectar hijackers y problemas de listing con IA
