## Project Context

### Vision
Doctor IA is a bilingual (Spanish LATAM + English) AI-powered emotional wellness funnel. The core product is a $17 ebook ("Tu Mente, Tu Salud / Your Mind, Your Health") sold through a Next.js landing page, promoted via YouTube + Reels, and supported by a Claude-powered chatbot that qualifies leads and handles post-purchase onboarding. The upsell is a personalized emotional health plan generated by Claude Sonnet ($97+).

### Tech Stack
- **Frontend**: Next.js 15 App Router, Tailwind CSS, shadcn/ui
- **Hosting**: Vercel (free tier for MVP, Pro when needed)
- **AI**: Anthropic Claude API — Haiku for fast/cheap, Sonnet for quality
- **Payments**: Stripe (primary) + Lemon Squeezy (global/VAT fallback)
- **Automation**: n8n (post-purchase delivery + email sequences)
- **Analytics**: PostHog + GA4
- **Email**: Resend (transactional)
- **Storage**: Airtable (MVP leads) → Supabase (scale)

### Budget
- Initial capital: $1,000 USD
- Monthly operating cost target: <$200 until 50+ sales/month
- Break-even: ~8 ebook sales/month

## Cost Optimization Rules (MANDATORY for all agents)

1. **Always use prompt caching** on system prompts longer than 1,024 tokens:
   ```json
   { "type": "text", "text": "...", "cache_control": { "type": "ephemeral" } }
   ```

2. **Default to Haiku** unless the task explicitly requires Sonnet quality. When in doubt, use Haiku first, escalate if output quality is insufficient.

3. **Use Batch API** for any task with ≥5 homogeneous items (scripts, chapters, copy variants). Batch API delivers ~50% cost reduction. See `.claude/skills/batch-content-creator/SKILL.md`.

4. **Pricing reference** (per million tokens):
   - Haiku input: $0.80 | Haiku output: $4.00
   - Sonnet input: $3.00 | Sonnet output: $15.00
   - With prompt caching (cache write): +25% on input
   - With prompt caching (cache read): -90% on input

5. **Alert threshold**: If a single agent task is estimated to cost >$0.10, stop and ask for human confirmation before proceeding.

6. **Batch API threshold**: ≥5 items of the same type → always use Batch API.

## Glossary

- **Zero-Point Story**: Fully automated by agents. No human review required. 0 story points.
- **R&I Story**: Review & Integration. Agent generates, human reviews and approves. Points reflect human effort.
- **Standard Story**: Agent develops, automated tests validate. Points reflect complexity.
- **ICP**: Ideal Customer Profile.
- **AIDA**: Attention → Interest → Desire → Action (copywriting framework).
- **Batch API**: Anthropic's async batch processing. 50% cheaper, 24h SLA.
- **Prompt caching**: Anthropic feature. Repeated system prompts cost 90% less on reads.
